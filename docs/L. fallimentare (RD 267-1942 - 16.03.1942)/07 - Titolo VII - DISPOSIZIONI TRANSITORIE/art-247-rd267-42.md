# Art. 247 - ***Delegazione dei creditori***

Nei fallimenti in corso le delegazioni dei creditori già costituite rimangono in carica. Tuttavia ove si debba procedere alla sostituzione di uno o più membri di essi, si applicano le norme dell'[art. 40](../02%20-%20Titolo%20II%20-%20DEL%20FALLIMENTO/02%20-%20Capo%20II%20-%20Degli%20organi%20preposti%20al%20fallimento/04%20-%20Sezione%20IV%20-%20Del%20comitato%20dei%20creditori/art-40-rd267-42.md).
