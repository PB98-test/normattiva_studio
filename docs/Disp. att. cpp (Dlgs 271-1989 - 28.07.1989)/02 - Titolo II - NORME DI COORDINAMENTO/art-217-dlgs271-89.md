# Art. 217 - ***Applicazione provvisoria di pene accessorie***

1. È abrogato l'[articolo 140 del codice penale](../../Codice%20Penale/01%20-%20Libro%20I%20-%20DEI%20REATI%20IN%20GENERALE/05%20-%20Titolo%20V%20-%20DELLA%20NON%20PUNIBILITÀ%20PER%20PARTICOLARE%20TENUITÀ%20DEL%20FATTO.%20DELLA%20MODIFIC/01%20-%20Capo%20I%20-%20Della%20non%20punibilità%20per%20particolare%20tenuità%20del%20fatto.%20Della%20modificaz/art-140-cp.md).   2. È abrogata, altresì, ogni altra disposizione che prevede l'applicazione provvisoria di pene accessorie.
