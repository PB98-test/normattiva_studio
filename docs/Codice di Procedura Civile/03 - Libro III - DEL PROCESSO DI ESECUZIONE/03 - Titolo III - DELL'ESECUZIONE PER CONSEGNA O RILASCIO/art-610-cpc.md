# Art. 610 - ***Provvedimenti temporanei***

Se nel corso dell'esecuzione sorgono difficoltà che non ammettono dilazione, ciascuna parte può chiedere al giudice dell'esecuzione, anche verbalmente, i provvedimenti temporanei occorrenti.[^agg-88][^agg-90]
