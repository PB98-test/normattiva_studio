# Art. 2419 - ***Azione individuale degli obbligazionisti***

Le disposizioni degli articoli precedenti non precludono le azioni individuali degli obbligazionisti, salvo che queste siano incompatibili con le deliberazioni dell'assemblea previste dall'[articolo 2415](art-2415-cc.md).
